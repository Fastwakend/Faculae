# 参考图 UI 与 Liquid Glass

当前交付为 1.6.0 (11)，菜单选中与未选中项统一图标占位，名称对齐；模型设置增加显示名称，底部标签显示 Logo 与此名称，详见 [UI-1.6.md](UI-1.6.md)。保留 [自定义图标](UI-1.5.md)、[原生液态玻璃二级菜单和精简推理按钮](UI-1.4.1.md)、[供应商多模型管理](UI-1.4.md)，以及推理弹窗无说明小字和稳定锚点布局。以下描述首页、历史和设置的基础布局。

按用户提供的三张手机截图调整原生 SwiftUI 界面。截图中的文字和内容仅作视觉参考；界面仍使用用户自己的对话与 API 配置。

## 对应界面

- 首页：白底、居中的当前模型透明标志与问候，左上角圆形历史按钮，右上角胶囊操作组，底部大圆角输入区。蓝色标签和右上角菜单均先显示供应商，再进入二级模型菜单；发送、停止和深度思考继续连接已有协议功能。
- 历史：iPhone 上向右推开聊天页的抽屉，占约 82% 屏宽；上方胶囊搜索框，下方按置顶、今天、昨天、过去 7 天与更早分组，底部进入设置。保留长按操作、滑动删除与导出。iPad 宽布局显示固定侧栏。
- 设置：大圆角 sheet、居中标题和右上角圆形关闭按钮，浅灰底、白色分组卡片与细分隔线。提供 API 与模型、数据管理、外观、字号、个性化及隐私信息。

参考图的语音和联网搜索没有对应的现有 API 能力，因此本轮将对应操作位置用于实际的服务切换、附件和发送。账户区域使用“本地空间”，没有复制截图中的个人姓名、头像或聊天内容。

## 原生材质

`Theme.swift` 的 `seekGlass` 使用 `#available(iOS 26, *)` 调用 SwiftUI 的 `glassEffect(.regular.interactive(...), in:)`。相关浮动组件放在 `GlassEffectContainer` 中。按钮使用交互玻璃，输入和搜索表面使用常规玻璃；玻璃内的标签以及设置内容卡片不再叠加另一层玻璃。

iOS 17–25 使用系统 `regularMaterial` 回退。系统管理玻璃的明暗与辅助功能适配；抽屉与滚动动画检查“减弱动态效果”。消息、代码与输入字号同时响应动态字体和应用内字号偏好。

没有用网页、CSS 模糊或截图背景来模拟 iOS 的材质。

全应用四处开关使用官方 `Toggle` / `SwitchToggleStyle`，推理等级使用官方步进 `Slider`；系统在 iOS 26+ 的交互过程中为控件滑块提供 Liquid Glass。控件本身没有额外包裹玻璃层，辅助功能表现由系统处理。历史筛选在系统 popover 内呈现真实开关。

## 资源与数据

欢迎标记来自用户提供的 `8692d9b1ced5eaa9380d49d4aaf5f5e3.jpg` 中的蓝色鲸形部分，裁成独立透明模板 PNG；图标位置保留宽高比例。它同时作为 Xcode asset catalog 资源和 xtool 根目录 PNG 打包。App 名称、Bundle ID 与应用图标保持为独立的 Seek API 客户端。

显示偏好通过 `AppStorage` 保存在本机 UserDefaults，隐私清单加入 `NSPrivacyAccessedAPICategoryUserDefaults / CA92.1`。1.4 将供应商与模型拆开，存档格式升级为 v2 并兼容 v1；存储路径和 Keychain 供应商 UUID 不变。每个模型独立保存推理等级与对话参数，聊天菜单使用原生 Menu 按供应商分组。

## 验证边界

已在 WSL 使用 Swift 6.4.1、xtool 1.24.0 与 iPhoneOS 27.2 SDK 编译整个 arm64 Release App，执行核心 XCTest，并检查 IPA 的主程序、图标、欢迎资源和隐私清单。具体结果见 [local-validation.json](local-validation.json)。

Windows / WSL 无法运行 Apple 的 iOS Simulator；本轮没有真实的 iPhone 屏幕渲染、交互或玻璃效果截图，不把编译通过当作视觉验收。签名安装后按 [DEVICE-TESTING.md](DEVICE-TESTING.md) 验收键盘、抽屉手势、VoiceOver、暗色、动态字体与透明度辅助功能。

API 依据：[Apple — Applying Liquid Glass to custom views](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)。


## 1.7 验收补充

见 [1.7 聊天与富文本](UI-1.7.md)：检查标题渐变模糊、两个顶部图标、白字灰边模型按钮、长模型名滚动与固定推理/附件/发送位置。检查推理按钮原生玻璃变形展开、点击外部收起、所有档位拖动时位置稳定、旋转与大字号，以及减少动态效果。

断网打开已有消息，检查表格、四种定界符公式、希腊字母、Mermaid、代码复制、浅/深色及流式补全；宽表格与代码只能横向滚动，正文高度变化应自动跟随。桌面渲染回归不能替代 iPhone 上 WebKit 和 VoiceOver 验收。普通构建使用已打包脚本和字体；仅修改渲染器时才需按 1.7 文档运行 npm 重建资源。


## 1.8 交互与滚动更新

最新实现与验收步骤见 [1.8 交互与滚动](UI-1.8.md)。1.7 的玻璃形变自绘浮层已替换为独立系统 Popover，避免与输入框融合；不再用全屏锚点层。两个选择按钮使用原生玻璃按钮，并在同一横向行中依次排列。

聊天只复用一个网页和原生滚动视图，移除逐条网页高度反馈链。普通聊天不加载图表库。顶部使用 iOS 26 的公开 UIScrollEdgeEffect.soft 和 UIScrollEdgeElementContainerInteraction；内容可以绘制到状态栏背景，控件仍避开 top safe area。旧系统保留系统材质回退。

桌面已覆盖 120 条历史消息滚动和 40 次增量输出；仍需安装 1.8 IPA 在真机检查标题按钮点击、Popover 分离、键盘 / 旋转 / 灵动岛 / 横向表格手势和滚动帧率。

## 1.9 玻璃展开与底部延伸

最新行为见 [1.9 界面与管理](UI-1.9.md)。推理面板改为专属容器内的原生玻璃变形，并与整个输入框保持间隔；仅展开时存在遮罩。聊天画布扩展到底部，消息经过输入框后方；侧栏搜索下移，供应商编辑页增加删除入口，左滑删除按钮恢复系统样式。上述 1.8 节记录当时实现，推理弹层和底部布局以 1.9 为准。原生动画、键盘、Home 指示条和删除持久化仍需真机验收。

## 1.10 推理回归与交互侧栏

最新实现以 [1.10 交互与回归修复](UI-1.10.md) 为准。修复输入框覆盖推理按钮锚点，缩小选择按钮；全屏水平拖动直接控制侧栏，线性吸附可中断。历史列表增加多选置顶和删除，移除筛选菜单，搜索栏与聊天顶部按钮对齐；顶部取消强烈 interactive 玻璃高光，设置页使用明确的系统分组背景。65 个核心测试和 16 组桌面渲染检查通过；原生触控、动画、手势竞争、安全区和实际配色仍需设备验收。
