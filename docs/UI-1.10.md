# 1.10 推理展开回归、跟手侧栏与对话多选

版本：1.10.0（15）。

## 推理按钮回归

1.9 中，推理按钮先为 `ChatControlAnchorsKey` 提供 reasoning 锚点；其父输入框随后使用同一 key 的 `anchorPreference` 写入只含 composer 的新值。这会替换子树已有值，导致展开层依赖的 reasoning 锚点丢失，点击后状态虽然开启却没有面板。

本版输入框改用 `transformAnchorPreference`，在保留 reasoning 值的基础上补充 composer。专属玻璃容器、Namespace、按钮到面板的原生玻璃变形和面板与输入框之间的 12 点间距保持。推理面板与附件面板打开时暂停侧栏手势。

这是根据实际调用层级定位并修正的源码问题。当前 Windows / WSL 无法运行 SwiftUI 触控；编译与 API 链接通过不等于已经在 iPhone 上复现并验证按钮打开。此处没有用模拟 Anchor 的浅层测试代替 SwiftUI 运行时检查。

## 紧凑按钮与顶部反馈

- 模型 / 推理按钮继续使用同款无着色的原生 `GlassButtonStyle`，改为 small control size；基准字号由 14 降至 13，标签最小高度由 32 降至 24，模型图标最小尺寸由 18 降至 16，按钮间距由 8 降至 6。字号仍随系统动态字体变化。
- 两个顶部按钮保持 44 点触控区域，背景使用不带 interactive 的原生玻璃。按压只有短暂透明度反馈，释放后立即恢复，不触发持续高光遮挡图标。设置页的圆形导航按钮采用相同处理。

## 原生连续侧栏

`InteractiveDrawer` 是独立 UIKit 容器，长期保留聊天和历史两个 SwiftUI hosting controller，显式传递 SwiftUI 环境；拖动不重建聊天网页。

- `UIPanGestureRecognizer` 覆盖聊天区域，没有边缘起点限制。水平意图明确时才开始，竖向阅读保持原有消息滚动。
- 拖动位移直接计算为侧栏宽度的比例，在手指移动时无动画赋值；没有“松手后才播放展开”的路径。
- 松手按距离与速度选择吸附方向，使用 linear `UIViewPropertyAnimator`，持续时间随剩余距离变化。再次拖动时先读取 presentation layer 当前位移，停止旧动画，再从该位置继续，避免跳到旧目标。
- 控件、文字编辑和横向模型条保留自己的交互；推理 / 附件 / 设置弹层打开时暂停侧栏手势。侧栏打开后，列表区域不被父手势抢占，仍支持左滑删除；可拖动露出的聊天表面关闭侧栏。
- iPad 宽布局保持固定侧栏；旋转、键盘和底部安全区变化时重新布局。聊天画布仍覆盖上、下安全区，正文仍在输入框玻璃后方滚动。

## 对话列表

- 搜索栏固定 44 点高度，上方 10 点、下方 8 点，与聊天顶部按钮同一垂直位置。移除原筛选按钮、只看置顶与搜索栏里的新建入口；输入内容后的清除按钮仍保留。
- 第一组标题右侧显示多选图标。进入后，顶部显示“选择对话”和退出按钮，每行增加选择圆圈；底部显示数量、批量置顶 / 取消置顶与删除。
- 删除前使用原生确认框；批量操作按 UUID 执行并只保存一次。删除当前生成的会话会停止该生成，未选中的对话不受影响。
- 批量删除只清理不再被其他历史消息引用的附件，重复引用只返回一次。空选择和已不存在的 ID 不会删除其他记录。置顶不改写消息和原日期分组依据。

## 设置分组背景

`SettingsScaffold` 在所有系统版本明确提供 `systemGroupedBackground`。设置卡片继续使用 `secondarySystemGroupedBackground`，浅色模式得到参考图四的浅灰画布和白色分组卡片。附件面板仍保留原生玻璃背景，不受此设置页修复影响。

## 验证

- 41 个 Swift 文件语法解析，24 个 App 源码完整加入工程。
- arm64 Release 编译、实际 SDK 27.2 元数据、原生玻璃 / Slider / Switch / 形变 API 与离线资源验证。
- 65 个核心 XCTest，包括新增 4 个批量操作用例：未选中记录和 JSON 往返保留、孤立 / 共享附件、置顶和取消置顶、空或过期选择。
- 16 组既有桌面 Chromium 回归：离线 Markdown / 公式 / 图表、120 条对话节点复用、40 次流式补丁、复制和分享桥接等。
