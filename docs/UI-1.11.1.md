# 1.11.1 消息定位、Logo、余额与实时活动修正

版本：1.11.1（17）。保留现有原生 Liquid Glass、全屏消息背景、供应商/模型配置与历史记录格式。

## 消息被滚到屏幕外

从源码确认了三个问题：WebKit 对短文档的原生 contentSize 有一屏高的下限；旧实现再添加上下 contentInset 并滚至原生底部，会把短消息向顶部推出可见区域。发送请求还在 DOM 更新前就消费了滚动指令；JavaScript 调用没有等待异步富文本渲染结束，原生端可能使用旧高度定位已有对话的新消息。

本版将标题和输入框的预留空间改为文档内部 padding，原生 contentInset 为零。消息背景与滚动视图仍铺到设备上下边缘，内容可以经过玻璃组件下方。短对话保持在标题下方；长对话按实际文档高度定位底部，最新内容底端留在输入框上方。

原生端等待 `updateTranscript` 完成及一次浏览器布局，并接收带会话 ID、渲染序号的实际文档高度。显式滚动请求在当前文档与原生尺寸就绪后才消费；同时观察 UIScrollView.contentSize 和视口尺寸变化，处理流式追加、键盘/输入框高度变化及异步图片/公式布局。用户主动拖动仍暂停跟随；回到底部会取消惯性。沿用单一 WKWebView，不新增逐条测高或滚动重建。

## 浅色模式 Logo

回复头部的 OpenAI 和 Claude Logo 在编码 PNG 前明确栅格化并通过 alpha 遮罩着色，不再依赖 UIImage.withTintColor 的渲染元数据。OpenAI 在浅色用黑色、深色用白色；Claude 用品牌橙色。导出的透明 PNG 为 24pt @3x，用户自定义图片保留原色。

## 余额两位小数

数值和数字字符串使用 Decimal 四舍五入，固定显示两位，例如 `12 → 12.00`、`12.5 → 12.50`、`1.005 → 1.01`。单位继续单独显示。JSON 路径提取不改变；`unlimited` 等非数值状态原样保留。不会将无法解析的状态误显示为零。

## 实时活动

Apple [实时活动文档](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities) 提醒：图片尺寸大于实时活动展示尺寸时，活动可能无法启动。上一版扩展直接打包 640×640 原图；本版使用独立的 30pt @3x（90×90 像素）透明资源，Xcode 与 WSL 两条构建路径均采用同一组小图，不再给扩展打包大图。

此外，上一版只在回复开始时尝试启动，生成中开启开关不会创建活动。本版始终保留当前回复的活动属性与最新状态：开关开启立即尝试应用，回到前台和系统重新允许活动时重新检查。Activity.request 只在前台调用，用户移除后不会在下一次前台事件自动重建同一条；可在后台生成设置中手动重试。

设置 → 应用 → 后台生成 → 实时活动增加系统权限、活动状态、实际错误域/错误码及重试入口。安装包缺少扩展时明确提示。新安装默认开启实时活动，已有用户保存的开关选择继续生效。

紧凑/展开灵动岛和锁屏的 Logo、模型显示名、计时、状态与 tokens 布局保持。系统决定展示位置与刷新时机；实时活动本身不延长 iOS 后台执行时间。任务结束后活动结束、计时停止。非灵动岛机型使用锁屏展示，未展开的岛内空间由系统分配。

安装必须保留并签名 `SeekAPI.app/PlugIns/SeekActivity.appex`，扩展与主应用使用匹配的标识和版本。若仍无显示，可在上述设置查看权限和具体错误；不能仅凭主 App 安装成功判断扩展也安装成功。

## 验证与剩余边界

- 75 项 SeekCore XCTest 通过，包含新增 Decimal 金额格式及非数值保留检查。
- 20 项桌面 Edge Chromium 回归通过：8 项富文本、12 项对话渲染；新增短对话、已有对话追加、视口/输入框高度变化及同高度会话切换确认。120 条历史消息、40 次流式更新继续复用原节点，滚动没有 DOM 替换或资源重新加载。
- 主应用与 WidgetKit 扩展均通过 iOS arm64 Release 编译链接，最低 iOS 17，实际 SDK 27.2；校验 IPA CRC、版本、扩展嵌入、框架链接、四个小尺寸活动 Logo 和离线渲染资源。
- 扩展链接仍有 LLD 的 iOS 平台支持警告（见 `artifacts/activity-build-wsl.log`）。编译和元数据通过不等于真机启动验证。

当前没有 Mac、iOS 模拟器或连接的 iPhone，因此未复现或验收原生 WebKit 滚动、键盘、PNG 栅格化外观，以及签名后灵动岛/锁屏的实际展示。桌面布局回归验证的是文档空间与渲染协议，不能替代 iOS UIScrollView 行为。余额的真实认证查询也未使用用户凭证实测。

真机重点复核：新对话发送短问答；长历史末尾继续发送；边生成边收起键盘/改变输入框高度；快速滚动后回到底部；浅/深色回复 Logo；余额 `0`/高精度数值；生成中开启实时活动、切后台/锁屏、完成状态及点击返回。若系统已允许但不显示，记录设置中的活动状态/错误码，并确认签名工具没有删除扩展。
