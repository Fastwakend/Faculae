# 1.12.0 实时活动内容、多会话生成与个性化

版本：1.12.0（18）。本次按用户补充的实际症状排查：iOS 27.2 上灵动岛已经出现，但展开后是没有内容的黑色长条；安装工具为爱思助手。

## 灵动岛黑条与扩展入口

在上一版 IPA 中确认了一个构建缺陷：WSL 手工链接的 WidgetKit 扩展从普通 Swift 程序的 `_main` 启动。扩展需要通过 Foundation 的 `_NSExtensionMain` 初始化。上游 [xtool 的扩展链接实现](https://github.com/xtool-org/xtool/blob/main/Sources/PackLib/Packer.swift) 同样链接 Foundation 并明确指定该入口。

本版修正 `scripts/build_activity_wsl.sh`，并增加实际 Mach-O 入口解析与发布检查。检查的是入口指令对应的符号，不只是二进制是否导入了某个函数。

```text
旧版 SeekAPI-1.11.1-unsigned.ipa：_main，入口回归检查失败
新版 SeekAPI-1.12.0-unsigned.ipa：_NSExtensionMain，入口回归检查通过
```

展开区域明确使用白色模型名、计时、状态及 tokens，锁屏活动使用深色背景和白色内容。Logo 从扩展资源加载，OpenAI 使用白色遮罩，Claude 使用橙色；资源读取失败时显示供应商品牌首字母。计时使用有限的八小时区间，结束后显示固定时长。

这修正了可确认的扩展入口缺陷及内容颜色问题。当前环境没有连接的 iPhone 或 iOS 模拟器，尚不能把二进制检查等同于黑条问题已经在真机消失。

## 显示测试与更频繁更新

进入「设置 → 应用 → 后台生成」，开启实时活动，点击「测试灵动岛与锁屏显示」。测试使用当前模型的显示名称、供应商 Logo 和 123 tokens，不调用 API；前台约 60 秒后结束，也可手动结束。生成真实回复时会先结束测试。

设置分别显示最近任务结果、活动状态、系统权限、更多更新权限、活动数量和错误。保留最近 16 条带时间的诊断记录，可通过系统分享导出；记录不包含 Key 或回复正文。「回复已完成」只表示任务结果，不再替代活动创建状态。

已在主应用 Info.plist 声明 `NSSupportsLiveActivitiesFrequentUpdates = true`，并读取 `ActivityAuthorizationInfo.frequentPushesEnabled`。Apple 对[该声明的说明](https://developer.apple.com/documentation/bundleresources/information-property-list/nssupportsliveactivitiesfrequentupdates)主要涉及 ActivityKit 远程推送的更新预算。本项目仍使用本地 ActivityKit 更新，没有新增 APNs 服务器：该声明不会保证每秒刷新，也不会增加 App 的后台执行时间。计时文字由系统计时视图展示；状态与 tokens 在进程可运行时按最多每秒一次合并提交。

主应用与 `PlugIns/SeekActivity.appex` 需要一起签名安装。当前没有证据认定爱思助手是问题原因；保持扩展并使用匹配标识和版本是安装要求。

## 切换对话时继续生成

「后台生成」增加原生开关「切换对话时继续生成」，默认开启。每个会话分别持有生成任务、运行 ID、用量记录、检查点和实时活动。切换或新建对话后，原会话继续接收，可以在另一个会话开始回复；对话列表显示生成指示。

停止按钮只取消当前会话；删除正在生成的会话只停止被删除的任务。关闭该选项后，离开当前会话会停止该会话并保存已收到的内容。运行 ID 防止被取消的旧请求在晚到的回调中覆盖新任务。

离开 App 后仍共享 iOS 分配的后台执行时间，最后一个任务结束后才归还时间。系统终止进程后不能恢复原 SSE 连接；后台恢复机会由系统决定，不会自动重复发送收费请求。

## DeepSeek 图片与已发送照片

移除根据 `deepseek-` 模型名前缀拒绝全部非文字附件的限制。DeepSeek Flash 图片使用 OpenAI 兼容协议的 `image_url` 内容发送，保留实际 API 模型 ID。是否支持该图片或其他附件由目标接口与模型判断；不再在客户端统一提示 DeepSeek 仅支持文字。

点击已发送图片可打开原生全屏预览，支持双指缩放、双击缩放和保存到相册。只有主动保存才申请 PhotoKit「仅添加」权限。预览和保存读取本机保存的发送附件，不依赖 WebKit 缩略图；现有导入流程会将图片缩至最长边 2048 像素并转为 JPEG，保存的是这份发送文件。

渲染器通过消息 UUID 和附件 UUID 请求预览，原生端再次核对图片归属。新增真实点击测试以及伪造点击/篡改 ID 回归；不会把任意网页路径当作本机文件读取。

## 头像与用户名

「设置 → 应用 → 个性化」增加头像和用户名。头像支持系统相册、图片文件和恢复默认；点击右上角保存后显示于对话列表下方。用户名最多 40 个字符，留空恢复「本地空间」。取消编辑不会提交草稿头像与名字。

头像在本机规范化为最长边 256 像素的 PNG，启动清理保留当前头像引用；未保存导入文件会清理。名字和头像仅保存在本机，不加入模型请求。
