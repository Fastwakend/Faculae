# 1.13.0 联网搜索、原生引用按钮与更多文件格式

版本：1.13.0（19）。用户真机截图已确认上一版灵动岛可显示内容，本版处理展开区域文字空间，并加入搜索、文档提取与通知权限检查。

## 灵动岛

展开区域的模型名称由 headline 改为 14pt，计时 13pt，状态和 tokens 为 12pt；Logo 为 20pt，减少行间距。模型名称可适度缩放，状态允许两行，计时和用量保留独立宽度，避免用量被截断。紧凑状态与锁屏布局保持。超长模型名仍按系统分配的区域截断。

## 搜索提供商与聊天

入口：「设置 → 服务 → API 与模型」，供应商列表下新增「搜索提供商」。可以添加多个 DeepSeek、Tavily、Brave、Serper、SearXNG 或自定义 JSON 接口，编辑、删除和选择当前服务。连接地址、结果数和解析规则保存在本机；搜索 Key 使用独立钥匙串命名空间，不写入配置或聊天导出。已有聊天与供应商设置兼容。

聊天底部新增原生玻璃地球菜单，开启联网或切换服务；关闭时不会调用搜索 API。开启时先以本次输入的问题检索，再把参考资料交给当前聊天模型，搜索服务与模型可以自由组合。附件不发送给搜索服务；搜索词只取本次输入，不自动发送历史记录。检索失败会明确报错，不把没有完成的检索当作成功。

生成任务内的搜索、用量和来源跟随原会话，不受切换聊天影响。搜索资料有大小上限，并标记为外部参考内容。搜索与网页抓取可能由供应商单独计费，不计入模型返回的 tokens。

### DeepSeek 官方 Search / Fetch

依据用户提供的[官方指南](https://api-docs.deepseek.com/zh-cn/guides/search/)，在 2026-10-30 核对了请求与响应：

| 用途 | 接口 | 请求 |
| --- | --- | --- |
| 搜索 | `POST https://api.deepseek.com/v1/tools/search` | `query`、`count`、`need_content` |
| 网页正文 | `POST https://api.deepseek.com/v1/tools/fetch` | `url` |

两者使用 Bearer Key。搜索词按官方上限限制为 128 个字符。结果解析 `title`、`url`、`summary` / `snippet`、`content`、站点名和日期。输入完整 HTTP/HTTPS 网页链接时直接 Fetch；也可设置搜索缺少正文时额外抓取前 0–3 个结果。搜索接口 URL 可改为用户的 HTTPS 网关，Fetch 使用其同目录的 `fetch` 路径。

### 通用接口

Tavily 使用 POST 搜索，Brave 使用 GET 与 `X-Subscription-Token`，Serper 使用 POST 与 `X-API-KEY`，SearXNG 使用 GET 和 `format=json`。SearXNG 实例须允许 JSON 输出。

自定义接口支持 GET 查询参数、POST JSON 模板、认证头名与 Key 前缀，以及结果数组、标题、URL、摘要、正文的 JSON 路径。支持点路径、数组索引和 JSON Pointer；顶层结果数组用 `$`。`{{query}}` 在 JSON 解析后替换，带引号或换行的搜索词不会改变请求结构。网络会话不保存 Cookie 或缓存，拒绝重定向，并限制响应大小。

「测试搜索」仅在用户主动点击时调用，可查看结果或错误；未使用真实用户 Key 做联网验收。

## 回复末尾的原生引用入口

每条有检索来源的回复末尾显示「X 个网页」和站点字母图标。**按钮本身使用 SwiftUI `.buttonStyle(.glass)`**，通过 UIHostingController 嵌入消息的原生 UIScrollView。WebKit 只预留位置并返回文档坐标，不用 CSS 模拟 Liquid Glass。按钮随原滚动视图移动；异步公式、图片布局后更新坐标，切换会话时移除旧按钮。

点击后打开原生 sheet，使用系统液态玻璃呈现，支持半屏/全屏拖动。列表显示序号、站点、日期（接口提供时）、标题、摘要与链接，点开用系统浏览器访问。来源保存于该回复，重启后仍可查看；保存摘要与元数据，不保留抓取的整页正文。来源列表是本次检索的参考网页，不保证模型实际逐条引用全部结果。旧回复没有检索记录时不凭空生成来源。

iOS 17–25 使用原生边框按钮与系统 sheet 材质；iOS 26+ 使用系统 Liquid Glass。原生按钮的实际触控、透明度、滚动叠放和 sheet 外观尚待真机验证。

## 文件格式

新增 DOCX、XLSX、PPTX、ODT、ODS、ODP、RTF、HTML/HTM，以及常见 Markdown、JSON、CSV、TSV、XML、日志和源代码文本。支持 UTF-8、带 BOM 的 UTF-16 和 GB18030；文本在发送前统一为 UTF-8。

办公文档通过系统 zlib 解压并解析正文 XML；Word 提取段落及页眉页脚/脚注，Excel 读取共享字符串、内联文本、数值及缓存值，保留空列与布尔值，PPT 按页文件编号提取文字。保留原文件名，以文字附件发送给三种协议。RTF 去除格式，HTML 移除脚本/样式后提取文字，不执行文档中的代码、宏或外部关系。

原文件最多 8 MB，提取文字最多 1 MB；图片与 PDF 的发送方式不变。损坏、加密或超限文档明确报错，不静默截断。暂不支持旧二进制 DOC/XLS/PPT、iWork、音视频转写、OCR、嵌入媒体或完整页面排版；这类文件可先导出 PDF 或现代办公格式。ZIP 仅作为办公文档内部结构解析，不开放通用压缩包上传。

## 任务通知权限

「设置 → 应用 → 后台生成 → 任务通知」新增系统权限、通知横幅、锁屏显示状态。尚未申请时提供申请入口，另可直接打开系统通知设置。进入页面和 App 回到前台时重新读取系统状态，区分未申请、拒绝、允许与临时静默权限；系统开通权限后清除旧的通知权限提示。任务通知的 App 开关与系统授权分别显示。

## 验证与边界

- 89 项核心 XCTest 通过，新增办公文档真实压缩夹具、字符编码、HTML 提取、损坏/超限拒绝，以及六类搜索请求、DeepSeek Fetch、JSON 模板转义、来源过滤/去重和历史保存检查。
- 24 项桌面 Edge Chromium 检查通过：8 项富文本、16 项对话渲染。新增来源按钮的回复身份、原生位置预留、滚动前后文档坐标和会话切换清理检查；120 行/40 次流更新继续保持滚动零 DOM 替换和资源重载。
- 61 个 Swift 文件静态验证，Xcode 包含 34 个应用源文件和 2 个扩展源文件成员；iOS arm64 Release 编译、扩展入口、版本、资源与 IPA CRC 检查通过。
- zlib 使用 iOS 系统库，源码不引入远程 Swift 包；WSL 依赖脚本已包含 `zlib1g-dev`。扩展链接仍保留已有 LLD 平台支持警告。

当前没有 Mac、模拟器或连接的 iPhone，未验证本次原生玻璃按钮/面板、文件选择与 RTF、灵动岛字号和通知系统跳转的真机效果；未进行搜索供应商的真实鉴权请求，也未完成 Apple 签名。桌面坐标回归不能替代 iOS WebKit 与原生子视图的设备验收。
