# 1.14.0 设置导航、附件导入与系统权限

版本：1.14.0（20）。保留已有供应商、模型、搜索配置和对话数据。

## 添加搜索提供商

用户补充的现象是：点击添加搜索提供商后，窗口短暂出现，整个设置流程退出到对话列表。

搜索编辑入口原先在 List 内的分区上管理 State 和 sheet。现在分区只发送编辑事件，由 API 设置页面持有稳定的编辑路由，使用现有 NavigationStack 的 navigationDestination 打开页面。搜索和模型供应商编辑统一在设置内部导航，不再在设置 sheet 上叠加编辑 sheet；保存或取消只返回 API 列表。删除确认也交由 API 页面持有。

这是根据代码结构和用户现象进行的修复；当前没有 iPhone 或 Simulator，尚未在运行时复现或确认消除自动关闭问题。

## 推理按钮

移除按钮内的大脑标志，只显示当前等级；取消最长等级文字的隐藏占位，按钮随 Low、Medium、High、Xhigh、Max 等文字的实际长度调整宽度。模型与推理按钮仍为苹果原生 `.glass` 胶囊按钮。

推理面板继续使用独立 GlassEffectContainer、glassEffectID 和 matchedGeometry 变形，弹簧 response 为 0.42、dampingFraction 为 0.68，使展开和收回更有弹性；开启系统“减弱动态效果”时关闭该动画。面板首次打开时记录来源位置，滑动原生 Slider 时不随底部按钮的文字宽度左右移动；收回时回到当前文字宽度的按钮。玻璃容器不包含输入框及其他按钮，保留与输入框 12pt 的间隔。

## 文件附件

- 去掉“办公文档提取文字后发送……”的固定提示。
- 文件入口改为原生 UIDocumentPickerViewController 的复制导入模式，多选后由系统文件提供商先准备本地副本。
- 选择器关闭后再导入，避免导入结果或错误提示与关闭动画同时呈现。导入期间禁止再次操作附件或关闭面板。
- 使用 NSFileCoordinator 协调读取，保留安全作用域访问；实际按块读取，最多 8 MB + 1 字节，不再依赖文件提供商可能缺失的 fileSize / isRegularFile 元数据。空文件、文件夹、超限或不支持的内容明确报错。
- 成功导入后返回聊天，显示真实附件；多选中部分失败时显示成功数量与失败文件原因。附件面板可纵向滚动，避免小尺寸窗口或大字号遮住下方内容。
- 文件依旧经过原有图片/PDF/办公文档/文本处理，存入 App 附件目录；每条最多 6 个附件、总大小 20 MB，提取文字最多 1 MB。取消选择不添加附件。

本地文件、iCloud 与第三方文件提供商的完整选择/下载/读取交互尚待真机验证，编译与核心文档解析测试不能替代该验证。

## 系统权限

入口：设置 → 关于 → 系统权限，图标为 checkmark.shield。

页面读取相机、最近照片、保存图片到相册、任务通知（含横幅与锁屏）、实时活动、更频繁更新和后台 App 刷新的系统状态。未申请的相机/照片/通知权限在点击时请求；已拒绝或需系统管理的项目打开 App 设置，通知项目使用公开的通知设置链接。进入页面和返回前台时重新查询，不在进入页面时批量弹出授权。

文件访问显示为“逐个文件授权”，因为 iOS 没有全局文件权限开关。部分照片、系统限制和未申请状态分别显示；受屏幕使用时间限制的权限无法由 App 解除。后台刷新总开关可能需要前往系统设置 → 通用，App 无公开接口直达该总开关。

这些是系统授权，与“后台生成”中的 App 功能开关分开；实时活动或通知仍需开启相应功能。没有添加未使用的麦克风、位置或联系人权限。

## 安装后核对

1. 从对话列表进入设置 → API 与模型 → 添加搜索提供商，等待数秒、切换接口类型和填写名称，确认页面保持打开；取消返回 API 列表，再添加并保存。
2. 重新进入编辑已有搜索提供商，返回后确认设置仍打开，已有供应商和对话未丢失。
3. 推理按钮切换 Low / Medium / Xhigh 等档位，确认按钮宽度跟随文字、面板和 Slider 不移动，并检查展开/收回动画。
4. 选择本地 TXT、DOCX/PDF 或图片后点击“打开”，确认返回聊天并出现附件；再检查 iCloud 文件、多选、取消、空文件和大于 8 MB 文件的提示。
5. 进入系统权限页面，分别申请未请求的权限、拒绝后点击跳转、在系统设置修改后返回，确认状态刷新。

IPA 未进行开发者签名；安装时需要同时签名主应用和 SeekActivity 扩展。
