# 1.15.2（25）：推理按钮弹性变形动画

## 反馈与实现

用户反馈 1.15.1 的推理菜单打开时没有从按钮变形而来的 Q 弹动画。上版源码使用两个条件分支分别添加、移除胶囊与面板玻璃；有相同的玻璃 ID，但几何过渡依赖原生插入、移除匹配。此前仅完成编译和符号检查，没有验证设备上的动画，不能将匹配 API 的存在当作变形效果已生效的证据。

本版改为一块持续存在的苹果原生 `glassEffect(.regular)` 表面：按钮与面板共用同一个 Button、玻璃 ID 和容器，直接以弹簧动画改变宽高、中心位置与圆角。按钮胶囊从实际位置扩展到居中的菜单面板，收起时反向回到按钮。弹簧参数为 response 0.42、dampingFraction 0.72，相比上版 0.30 / 0.86 增加回弹幅度。

- 原生玻璃表面不再在两个条件分支间替换，也不再对玻璃加源按钮的裁切 mask。收起尺寸和可点范围取按钮与横向控件栏的可见交集；文字单独裁切，避免长模型名时覆盖其它按钮。
- 按钮标题只存在一份，随表面移动并短暂淡入、淡出，不拉伸字体。菜单内容仍保持最终位置和尺寸，通过与玻璃同步展开的圆角遮罩逐步显露，原生 Slider 不做缩放或重复创建。
- 同一显示状态可以立即反向切换，没有 Task 延迟、关闭锁或等待动画完成的回调。动画只作用于玻璃和内容的显露遮罩；关闭立即隐藏菜单内容并恢复按钮命中。
- 保留独立玻璃容器，防止与输入框、模型或搜索控件融合；菜单继续在水平方向居中，选择不同长度的等级不改变展开位置。
- 遵循系统“减弱动态效果”。开启时直接切换状态。iOS 17–25 继续使用原生 popover 回退。

采用的苹果公开 API 指引：[Applying Liquid Glass to custom views](https://developer.apple.com/documentation/SwiftUI/Applying-Liquid-Glass-to-custom-views)。本版采用持续表面的几何动画，不依赖两个玻璃节点的插入、移除匹配来启动变形。

## 本机验证与范围

68 个 Swift 文件语法解析、工程引用检查通过。89 项核心 XCTest、10 项分享文件队列测试重新执行并通过。主 App、实时活动和分享扩展完成 iOS arm64 Release 编译、链接和 IPA 打包，扩展保持 `_NSExtensionMain` 入口。原生玻璃、Slider、Switch 等符号和版本资源继续接受发布检查。

当前环境是 Windows + WSL，未连接 iPhone，也没有 iOS Simulator。本版未验证真机 Q 弹视觉、快速开关、横向裁切、键盘联动、VoiceOver 或 FPS。编译与静态检查不能证明设备动画表现。渲染器资源未改，复用 1.15.0 的 25 项桌面渲染检查结果，没有重复运行。

真机验收：反复点击推理按钮、点击菜单外关闭，并在收起途中立即重新打开；确认玻璃由按钮位置伸展到居中的面板、带适度回弹且无双层按钮。拖动 Slider 切换 Low、Medium、Xhigh 等档位，确认面板不移动；再检查键盘显示、长模型名使控件横向滚动、浅深色和“减弱动态效果”。
