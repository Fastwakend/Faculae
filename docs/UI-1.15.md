# 1.15.0（23）：系统分享、文件导入及界面调整

## 系统分享

新增原生 `SeekShare.appex` 分享扩展，以及主 App 文件打开接口。扩展通过 `NSItemProvider` 在临时 URL 有效期内复制文件；确认后原子提交 App Group 文件批次，回到主 App 后导入确认列表，再添加到当前附件草稿。只在用户发送消息后上传给供应商。详见 [分享与签名配置](SHARING.md)。

- 文件提供方设置 45 秒超时；晚到的回调不能重复完成或写入。
- 文件数量、单文件与总量限制分别为 6、8 MB、20 MB；文件名清理和队列读取限制避免路径越界。
- 未提交批次对主 App 不可见，取消不提交；导入失败保留已提交的原批次，成功后移除。
- `SeekShare` 与 `SeekActivity` 均使用 Foundation 的 `_NSExtensionMain` 入口。
- 主应用与分享扩展需要有效且一致的 App Group 签名权限。WSL 不生成开发者签名；提供权限模板与直接“用 Seek API 打开”的备用入口。

## 附件一直加载

导入从 UIDocumentPicker 的实际选择结果直接开始，不再依赖嵌套 sheet 的 `onDismiss`。`asCopy: true` 已要求文件提供方交付本地副本，后续移除再次执行的 `NSFileCoordinator`，改为有大小上限的本地 FileHandle 读取。文件内容仍经过原有图片/PDF/Office/RTF/文本解析和真实保存。

完成后面板立即显示已选数量及成功文件名，点“完成”回到聊天。部分失败会显示具体文件和错误。取消选择不添加附件。不在文件选择器退场动画期间同时关闭父面板。

目前没有设备运行日志能证明此前卡住的唯一原因；本版修正上述生命周期与重复文件协调两处风险，真机仍需复测本地及云端文件。

## 界面

- 灵动岛展开状态：继续使用 leading/trailing 区域，横向系统边距 28pt、纵向 14pt；左列再向内 4pt、向下 5pt，右列向内 12pt、向下 7pt，计时列宽 82pt。内容远离圆弧边缘，不添加背景或遮罩，也不恢复造成大块空白的底部单区域方案。外形与相机避让仍由 iOS 决定。
- 推理菜单：宽度上限由 316pt 增至 360pt，屏幕两侧至少 16pt，水平居中；底边锚定打开时按钮的底边，因此覆盖输入区域。原生 `GlassEffectContainer`/`glassEffectID` 变形动画、原生 Slider、减弱动态效果支持，以及与输入框玻璃容器隔离均保留。滑动改变等级文字时位置不变。
- 网页来源按钮：SwiftUI 原生玻璃按钮在宿主宽度内靠左布局，其左边缘与复制按钮的布局左边缘一致，保留原生按钮及点击来源窗口。
- 个性化头像区域只保留 PhotosPicker 相册选择入口。
- 个性化新增“开启竖屏锁定”，复用原生 `SeekSwitch`，iOS 26+ 使用系统 Liquid Glass 开关外观。通过 `UIApplicationDelegate` 支持方向与 `UIWindowScene.requestGeometryUpdate` 更新方向；偏好持久保存，不使用私有强制旋转接口。iPad 多任务等系统限制可能暂时拒绝几何更新。
