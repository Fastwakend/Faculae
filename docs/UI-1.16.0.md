# 1.16.0（26）：分享导入、1GB 附件与回答导出

## 分享导入

用户截图中的“共享空间不可用”来自 `containerURL(forSecurityApplicationGroupIdentifier:)` 返回空值。主应用与扩展之间的直接交接需要签名授予同一个 App Group；IPA 内的权限 XML 不能自行授予这项权限。

本版保留权限正常时的直接队列导入，并在共享目录不可用或无法创建批次时自动切换为系统“文件”中转。扩展先将分享文件以分块方式保存在自身临时目录，再打开 `UIDocumentPickerViewController(forExporting:asCopy:)`，由用户选择“我的 iPhone → Seek API → 导入附件”。返回主应用后显示导入确认，添加到当前草稿，不自动发送。首次使用应先启动一次主 App 创建此目录；也可保存到任意位置，再从聊天附件的“文件”入口选择。

主 App 启用 `UIFileSharingEnabled` 和 `LSSupportsOpeningDocumentsInPlace`，在 Documents 下创建可见的“导入附件”目录；聊天历史、Keychain 和附件存储继续位于原位置。取消导入保留文件，成功添加后仅删除已经消费的文件。直接“用 Seek API 打开”入口仍可用，大文件复制离开主线程，安全访问授权保持到复制结束。

此中转方式需要用户选择保存目录，不能在扩展中无授权访问主 App 沙盒，也不使用强制唤起主 App 的响应链或私有 API。正确签名的 App Group 安装继续使用原来较短的直接导入流程。

## 1GB 附件

- 单文件上限统一为 1,073,741,824 字节（1 GiB，界面显示 1 GB），每条最多 6 个附件，总量最多 6 GiB。去除旧的 8 MB 单文件、20 MB 合计限制。
- 文件选择、Open In 和分享扩展通过 192 KiB 缓冲复制，检查实际字节数，拒绝目录、符号链接和超限文件；失败、取消会清理未完成副本。
- PDF 校验文件头后直接复制；图片通过 ImageIO 从 URL 下采样为聊天图片；大 UTF-8 文本分块校验、保存。小文本继续兼容 UTF-16 / GB18030 等原有编码。
- 办公文档用映射的压缩包读取选择的正文 XML，不再复制整个压缩包；正文解压和提取文字的保护上限保留。RTF / HTML 大正文仍需转换为 UTF-8 TXT 或 PDF，不能将文件导入上限理解为无限制的本地正文解压或模型上下文容量。
- App 不再把所有附件加载成 Data 字典。请求正文在磁盘生成，按块写 UTF-8 JSON 和 base64；上传使用 `URLSessionUploadTask(fromFile:)`，通过数据代理继续增量接收 SSE。请求取消时中止上传并清理临时 JSON，继续拒绝重定向，避免转发凭据。
- 供应商实际支持的文件类型、请求大小和 token 上限由接口决定。本地 1GB 上限不改变供应商限制，没有测试真实 1GB API 上传。

## 回答末尾保存菜单

原分享图标改为原生 `UIButton + UIMenu`。菜单跟随该条回答的按钮位置，iOS 26+ 使用系统液态玻璃样式；复用按钮并根据文档坐标更新位置，不增加 WebView 或重新加载消息。

| 选项 | 内容 | 去向 |
| --- | --- | --- |
| 保存为TXT文件 | 当前这条回答的可读文本，去除 Markdown 样式和代码块操作标签，公式保留一份原始 TeX | 系统文件保存窗口 |
| 保存为MD文件 | 当前这条回答的原始 Markdown | 系统文件保存窗口 |
| 保存为图片 | 点击时整段当前对话，包含历史提问、回复、模型标题、附件与渲染的公式/表格 | 系统相册，首次按需申请添加照片权限 |

图片使用单独的非持久 WKWebView 渲染完整对话，移除输入框预留空间与复制/分享/重试操作；生成整段 PDF 后栅格化为 PNG，保留深浅色。图片像素预算为 2400 万、单边最多 32000 像素；过长对话整体缩小，内容不按当前屏幕截断。该过程不滚动或改变正在使用的聊天 WebView。

## 验证

- 73 个 Swift 文件静态解析，42 个 App 源文件、2 个实时活动和 3 个分享扩展编译成员检查通过。
- 96 项核心 XCTest 与 10 项分享队列回归通过。新增检查覆盖 1GB / 1GB+1 稀疏文件边界、多块复制、取消清理、跨块 UTF-8、磁盘 JSON 与三种协议原请求的一致性、base64 跨块和无效输入清理。
- 8 项富文本、20 项对话桌面渲染检查通过。新增原生保存按钮的坐标/生成态检查、TXT 正文及公式检查、120 条历史完整导出准备、深浅色截图。
- 主 App、实时活动与分享扩展完成 iOS arm64 Release 编译和打包；IPA 资源、版本、原生控件符号、两个扩展的 `_NSExtensionMain` 入口和 ZIP CRC 接受发布检查。
