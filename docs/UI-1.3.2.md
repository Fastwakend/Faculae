# 1.3.2 (6)：稳定推理弹窗的锚点

用户反馈滑动推理 Slider 时，弹窗会左右移动。源码中，popover 直接锚定在输入栏的推理按钮，而按钮标题会随等级更新：例如“推理 · Low”切换为“推理 · Medium”。原来的自适应标题会改变按钮宽度和锚点中心，位于横向 ScrollView 内时也可能改变滚动内容的布局。

修复包含以下布局调整：

- 推理按钮使用隐藏的候选标题参与布局，始终预留当前模型全部档位所需的最大宽度。实际等级文字实时更新；候选占位文字不参与辅助功能朗读。字体仍随系统缩放，未使用固定像素宽度。
- popover 显式锚定按钮 bounds，从按钮上方展开。Slider 不会改变这一锚点的尺寸。
- 弹窗打开期间暂停底部选择器横向滚动，关闭后恢复。
- 弹窗右上角的等级文字同样预留当前模型全部档位所需的最大宽度，保留原有 316pt 面板宽度，不固定面板高度。

原生 `popover` / `Slider`、系统 Liquid Glass、四组推理档位和保存行为保持一致。屏幕旋转、键盘或可用空间改变时仍由系统合理调整弹窗位置，避免锁死屏幕坐标。

42 项核心测试与 arm64 Release 编译通过，安装包仍链接 iOS SDK 27.2、最低支持 iOS 17。Windows / WSL 无法运行 iOS Simulator，本次没有在设备上复现或验证弹窗位置，编译结果不能替代手势验收。

签名安装 1.3.2 (6) 后的检查：依次选择四种模型，打开推理弹窗，连续往返拖动全部档位并点击下方档位文字；弹窗位置和滑轨长度应保持稳定，右上角数值及底部按钮值应正确更新。也检查旧配置首次打开、较大系统字体、较窄屏幕和横向滚动后的入口位置；关闭弹窗后，底部横向滚动应恢复。
