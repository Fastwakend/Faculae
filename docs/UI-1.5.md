# 1.5.0 (10)：每模型图标

在「设置 → API 与模型 → 供应商 → 模型 → 模型图标」选择：

- 自动识别，沿用模型名和协议的现有 Logo 匹配。
- OpenAI、DeepSeek、Claude、Gemini 四个内置 Logo，可与 API 协议自由组合。
- 从系统相册或文件导入图片，支持即时预览、重新选择和移除。透明 PNG 保留透明底。

保存模型后仍需保存供应商，取消编辑不提交修改。模型图标显示于聊天首页、供应商列表、模型列表及新回复头像；回复保存发送时的选择，之后改图标或删除模型不会改写既有回复。旧回复缺少图标字段时沿用自动识别。

## 本机处理与保存

`APIModel.iconStyle`、`customIconID` 以及回复的对应字段均为可选，已有 v1 / v2 存档无需补充字段即可读取。Keychain 和供应商 UUID 不变，图标不会改变模型系列、协议、推理档位或请求内容。

ModelIconStore 在独立 actor 中解码图片，以 ImageIO 缩略图处理方向，最长边 256 像素，重编码 PNG 保留 alpha 并移除原始元数据。源文件上限 20 MB，生成文件上限 512 KB。文件以随机 UUID 存入 `Application Support/SeekAPI/ModelIcons/`，使用原子写入、系统文件保护并排除备份。显示缓存最多 64 张 / 16 MB。

配置与回复只保存 UUID 引用，不重复存放图片。启动时保留所有模型及历史回复引用的图片，清理不再使用的文件；保护本次启动新导入的图片，防止延迟清理与编辑竞争。取消导入任务后不提交图片，取消编辑留下的未引用图片下次启动清理。文件丢失或无法显示时回退为自动 Logo，不影响聊天。

自定义图标不作为聊天附件，不进入 OpenAI、Gemini 或 Claude 请求，也不进入 Markdown 导出。使用系统 PhotosPicker 选择单张图片，无需请求整个图库权限；文件访问使用系统授权范围。

图标设置使用原生 Form / Picker / PhotosPicker / fileImporter，沿用各级设置的玻璃导航按钮。此版本同时包含 [供应商原生二级菜单和精简推理按钮](UI-1.4.1.md)。

## 验证

56 项核心 XCTest 中有 4 项图标测试，覆盖旧字段缺失的解码、每模型独立保存、历史回复引用不受修改和删除影响，以及三种协议的请求与未设置图标时完全相同。已完成工程静态检查、arm64 Release 编译和 IPA 校验，见 [local-validation.json](local-validation.json)。

图片解码、文件保护、图库 / 文件选择器、缓存、清理与原生界面的运行时行为尚未在真机验证，设备步骤见 [DEVICE-TESTING.md](DEVICE-TESTING.md)。
