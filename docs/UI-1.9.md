# 1.9 玻璃控件、供应商管理与底部延伸

版本：1.9.0（14）。

## 按钮与推理展开

- 模型与推理按钮统一使用无着色的苹果 `GlassButtonStyle`，系统主文字色随浅色 / 深色模式变化，不再给模型按钮添加深灰底或强制白字。两者仍相邻，随模型显示名称宽度一起移动。
- iOS 26+ 的推理展开使用苹果 `glassEffectID` 和 `glassEffectTransition(.matchedGeometry)`。临时源形状与目标面板位于专属 `GlassEffectContainer(spacing: 0)` 和专属 Namespace 内，模型按钮、输入框以及顶部按钮不参与该变形。
- 目标面板位于整个输入框上沿至少 12 点之外，宽度不超过 316 点；屏幕较窄时缩小宽度，垂直空间不足时内容可滚动。底部位置由按钮和输入框锚点决定，不随档位文字改变。
- 只有展开期间才创建遮罩和 GeometryReader；关闭后整层移除，避免覆盖历史和新对话按钮的触控。点击外部或 VoiceOver 退出可收起，系统减少动态效果设置关闭变形动画。
- Slider 保持苹果原生步进组件。iOS 17–25 使用系统 Popover 回退。

## 供应商与模型删除

- 编辑已有供应商时，底部新增明确的“删除供应商”按钮；供应商列表同时支持长按菜单和左滑删除。
- 删除前由系统确认框显示范围：移除供应商、其模型与 Key，保留聊天记录。复用现有 Keychain 删除与配置持久化逻辑；生成中不能删除，至少保留一个供应商。
- 模型和供应商的左滑删除操作均明确使用 `.automatic` 按钮样式、垃圾桶图标、删除文字、白色前景和红色背景，不再继承设置页的 `.plain` 样式。关闭整行左滑直接删除，保留可见操作按钮。
- 模型删除仍是供应商的编辑草稿，点击右上角保存后一并持久化；取消编辑不保存模型移除。最后一个模型继续受保护。

## 顶部与底部布局

- 根布局使用顶部对齐的明确尺寸，历史侧栏只使用设备安全区域的高度，不随扩展的聊天画布向上偏移。搜索栏顶部间距由 12 点增加到 24 点。
- 聊天画布同时包含上、下安全区，背景与消息滚动视图延伸至设备底端。输入框叠放在消息视图上，消息可以从原生玻璃后方经过。
- 输入框控件仍留在 Home 指示条 / 键盘上方。只测量一个输入框的实际高度，使用该高度加底部安全区作为消息滚动留白；末条消息与“回到最新消息”按钮仍可完整露出。没有恢复逐条消息高度测量或网页重建。
- 顶部继续使用 iOS 26 的 `UIScrollEdgeElementContainerInteraction` 与系统 soft 滚动边缘模糊。

## 验证与设备验收

Windows / WSL 已执行 Swift 语法与工程引用检查、arm64 Release 编译、61 个核心 XCTest、16 组桌面 Chromium 排版 / 增量渲染回归。IPA 检查核对版本、资源、实际 SDK 27.2 和原生玻璃变形 API 的弱链接。

没有连接 iPhone 或 iOS 模拟器。下列行为仍需设备验收，桌面浏览器不能替代：

1. 灵动岛设备打开侧栏，搜索栏完整位于安全区下方；旋转和 iPad 分屏后重复检查。
2. 短 / 长模型显示名称下，两个选择按钮颜色一致；推理从按钮展开，目标面板与输入框保持间隔；反复拖动各档位不移动面板。
3. 关闭推理面板后顶部按钮可点击；VoiceOver 能进入滑条和退出面板；减少动态效果时不播放变形。
4. 供应商编辑页删除、取消确认、删除当前 / 非当前供应商、保留最后一个、Keychain 移除及重启后的持久化；历史消息仍在。
5. 编辑页左滑模型，红色操作区可见白色删除文字和垃圾桶图标；保存生效、取消不生效；最后一个模型不允许移除。
6. 长对话滚动时内容进入输入框玻璃后方并延伸至屏幕底端；末条消息、附件、多行输入、键盘交互和 Home 指示条无重叠。

编译后的 IPA 未使用开发者证书签名，需自行签名安装。
