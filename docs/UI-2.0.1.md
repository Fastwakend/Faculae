# Seek API 2.0.1（29）

本版处理生成图和拍摄照片预览中保存到相册时报 `PHPhotosErrorDomain 3302` 的问题，并调整图标颜色和整段会话的 Markdown 导出。

## 相册保存

原流程把 App 内以 UUID 命名、没有扩展名的附件 URL 传给 PhotoKit，同时使用附件元数据指定类型。拍摄照片和生成图片共用这条路径。Apple SDK 将 3302 定义为 `invalidResource`，不是相册权限拒绝；资源路径、实际编码或元数据均可能影响资源验证。

现在统一使用 `PhotoLibrarySaver`：

- ImageIO 读取真实图片类型、尺寸和完整资源，不依赖附件名称或 MIME 字段判断格式。
- 向 PhotoKit 提交图片 `Data`，同时设置实际类型和匹配扩展名的原始文件名，不再提交无扩展名的附件文件 URL。
- JPEG / PNG / HEIC / HEIF 通常保留原始编码；WebP 等不直接适合照片库的格式在后台转成 PNG 副本，原附件不变。
- 如果第一笔事务明确返回 `invalidResource`（3302），从原图片解码并以正确方向重新编码为 PNG，再提交一次。其他错误不自动重试，避免对结果不明确的事务重复添加。
- PNG 转换保持图片尺寸和透明通道；权限不足时显示权限提示。
- 生成图、拍摄照片及整段会话图片保存均复用此入口。

这针对共同资源提交路径进行了修复。当前 Windows / WSL 环境不能运行 iOS PhotoKit，因此尚未在设备上复现或确认 3302 已消失，不把交叉编译成功当作相册保存验收。

## 界面和导出

- 生图参数的八个比例矩形图标与「自定义比例」图标改为固定白色的原始图像，防止系统菜单将模板图标重新着色。
- 对话列表长按菜单的置顶、重命名、导出、删除四个图标均改为白色；删除仍保留系统的破坏性操作语义。
- 「导出对话」改名为「导出对话为MD文件」。点击后创建真实 UTF-8 `.md` 文件，使用系统文件保存器选择位置，包含整个会话的标题、全部用户与助手消息及附件名称。保留原始 Markdown、代码和公式；附件原文件不嵌入 MD。
- 图片预览的「完成」、保存图标与加载指示使用白色。提示使用局部设置白色 tint 的原生 UIAlertController，「知道了」为白色，不改变其他页面的全局弹窗样式。
