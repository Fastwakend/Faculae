# 2.1.0（30）：参考图、触觉反馈、对话分支与照片选择

## 生图参考图

生图模式的加号入口与聊天模式一样可用，可通过最近照片、拍照、相册或文件添加参考图。发送时，OpenAI 有图请求使用 `POST /images/edits` 和多图 `image[]` multipart；无图仍使用 `/images/generations`。Gemini 使用 `generateContent`，将图片作为原生 `inlineData` 与提示词一起发送。

每条消息最多 6 个附件，沿用单文件 1 GiB、总计 6 GiB 的客户端边界。生图接口接收 JPEG、PNG、WebP 图片；上传入口会将相册和相机图片规范化为 JPEG。文档不冒充图片发送，需先转换为图片。平台和具体模型仍可能有更低的图片数量、大小、格式与参数限制。客户端上限不代表供应商保证接受这么大的请求。

OpenAI multipart 和 Gemini base64 JSON 均分块写入临时请求文件，再通过文件上传，取消或完成时清理。图片字段名称、图片二进制、跨块 base64 还原与失败清理已由核心测试检查。只有本次用户消息显式添加的参考图进入本次生图请求，不自动回传所有历史生成图。只添加图片、不写文字时使用默认参考图提示词。

尺寸、质量、格式、审核、透明背景和压缩仍使用原生参数面板与既有协议映射。Gemini 的质量和透明背景为提示词偏好，格式和压缩在本机转换；具体说明见 [2.0 生图说明](UI-2.0.0.md)。

## 触觉反馈

「设置 → 应用 → 触觉反馈」增加波形图标入口，包含全局、开关、侧边栏、列表项、卡片、消息生成六个开关，以及强度 Slider 和百分比。全部使用 SwiftUI 原生 `Toggle(.switch)` 和 `Slider`，由 iOS 26+ 提供系统液态玻璃外观。

全局开关控制全部反馈；各分类独立保存，关闭全局不会抹去分类设置。强度为 0 时静音，释放 Slider 时预览当前强度。使用系统 `UIImpactFeedbackGenerator`，强度范围 0–1，实际振动仍受设备硬件和系统设置影响。

- 开关：用户切换原生开关时触发，初始化与程序恢复状态不触发。
- 侧边栏：通过拖动或按钮打开、关闭对话列表时触发。
- 列表项：选择对话、聊天模型、供应商、搜索服务及模型列表等操作时触发。
- 卡片：用户展开或关闭思考过程时触发，消息重绘不触发。
- 消息生成：开始、前台流式接收、完成、停止或失败时触发；流式间隔至少 0.18 秒，避免每个 token 都振动。

反馈仅在 App 前台播放，后台生成不持续振动。设置保存在本机 UserDefaults，不进入 API 请求。

## 分支到新对话

助手回复底部顺序为「复制、分享、分支到新对话、重新生成」。新按钮使用分支图标，与分享按钮同为 40 × 40 点。已完成的历史回复均可分支，重新生成仍仅出现在末条回复。

分支包含所选回复及之前的全部消息，保留文字、思考内容、模型元数据、搜索来源、图片及生图参数快照。新会话及每条消息具有独立 UUID，记录父会话和父消息引用，标题增加「· 分支」。操作不自动调用模型，原会话保留。切换时是否继续原会话生成，遵循原有「切换对话时继续生成」设置。

附件复用同一文件 ID，全局引用检查确保删除原会话或分支时，不会提前删除另一会话仍使用的图片。新旧会话的消息内容分别修改、保存。纯图片回复同样有分支入口。

## 最近照片选择

针对点击第 1、3、5 张却选择第 2、4、6 张的反馈，最近照片格子、按钮标签与按钮本身统一为 94 × 104 点，并显式限定点击区域，避免 `scaledToFill` 的溢出图片区域参与相邻按钮命中。

选择由 `PHAsset.localIdentifier` 直接关联实际导入的附件 ID，不从数组尾项推断。异步缩略图回调核对当前照片身份，并忽略取消或已离开视图的回调，防止旧缩略图替换新照片。
