# Seek API 2.3.1（33）：生图比例图标与分支标题

生图参数的八个预设比例矩形图标和「自定义比例」图标不再固定为白色。矩形绘图作为模板的透明度遮罩，由原生菜单按当前外观着色；自定义比例使用原生 SF Symbol 标签，随系统浅色、深色及 App 外观设置切换。

修复入口共用 `ImageParametersContent`，覆盖聊天生图模式的「参数 → 尺寸 → 图像比例」菜单，以及「模型设置 → 生图默认参数」中的同一菜单。比例形状、顺序和选择行为保持原样，继续使用系统原生液态玻璃菜单。

2.0.1 的固定白色图标实现是本问题的直接来源：`.alwaysOriginal` 将白色像素带入原生浅色菜单，无法继承菜单前景色。本次仅将比例图标改为模板着色，其他此前单独指定白色的图标不在本次调整范围内。

分支功能创建的新对话标题改为「分支•原标题」，例如「分支•关于傅里叶变换的讨论」，替代原先的「原标题 · 分支」。标记存储在标题开头，长标题在列表中尾部截断时，仍先显示分支标记。

验证：语法及工程引用检查、129 项核心 XCTest、10 项分享导入文件测试、主 App 和两个扩展的 iOS SDK 27.2 Release 交叉编译、IPA 完整性与源码一致性检查。本版为图标渲染和标题格式调整，没有新增不能复现菜单外观的替代测试。本机无法运行 iOS 菜单，尚未执行原生浅深色截图和对比度验收；渲染器和 WebP 未改动，沿用已记录结果。

真机待验：在聊天参数面板与模型设置页分别打开比例菜单，切换 App 浅色/深色/跟随系统，确认八个矩形和自定义图标均清晰；菜单打开后改变系统外观再重开，确认着色更新；检查降低透明度、增强对比度及各比例选择仍正常。对长标题会话创建分支，确认对话列表、聊天标题和重新启动后均使用前缀格式。
