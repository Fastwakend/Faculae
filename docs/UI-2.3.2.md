# Seek API 2.3.2（34）：黑白菜单图标与分支标题

新创建的分支对话标题使用「分支 · 原标题」，中点前后各一个空格，标记位于标题开头。

下列图标按 App 当前外观明确使用深色模式纯白、浅色模式纯黑：

- 生图参数中八个预设比例的矩形图标。
- 「自定义比例」图标。
- 对话列表长按菜单中的置顶/取消置顶、重命名、导出对话为 MD 文件、删除四个图标。

共用 `MenuArtwork.monochromeColor` 和 `monochromeSymbol`，读取 SwiftUI 的 `colorScheme`，并使用原始图像像素交给原生菜单，避免菜单 tint 或破坏性操作角色再次改变图标颜色。矩形图标用同一颜色绘制。跟随系统、手动浅色和手动深色均由 App 的现有外观设置传递，重新构建菜单时取得当前颜色。删除按钮保留原生破坏性操作语义。

比例菜单的改动覆盖聊天参数面板和模型设置页的生图默认参数。继续使用原生 Menu / Context Menu 和系统液态玻璃。

验证：语法和工程引用检查、129 项核心 XCTest、10 项分享导入文件测试、iOS SDK 27.2 下主 App 与两个扩展的 Release 编译，以及 IPA 完整性、版本和交付源码一致性检查。本版属于颜色和标题格式的小范围修改，没有新增替代原生渲染的浅层测试。渲染器、WebP 沿用已有结果。本机无 iOS 运行环境，未执行原生菜单截图与切换外观的真机验收。

待真机验收：

1. 浅色模式下，分别打开聊天生图参数和模型默认参数的比例菜单，确认八个矩形及自定义图标均为黑色；深色模式均为白色。
2. 对话列表长按一条普通及一条置顶对话，确认四个菜单图标在浅色为黑色、深色为白色，包括删除图标。
3. 检查 App 手动外观和跟随系统外观，切换后重新打开菜单，确认颜色更新；检查降低透明度与增强对比度。
4. 长标题对话创建新分支，确认列表、聊天标题和重启后均显示「分支 · 原标题」。
