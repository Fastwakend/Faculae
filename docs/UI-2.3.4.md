# Faculae 2.3.4 (36)

在「设置 → 关于」的「应用版本」下方增加两个外部链接入口：

| 选项 | 图标 | 目标 |
| --- | --- | --- |
| GitHub | 系统代码符号 | [Faculae 项目仓库](https://github.com/Fastwakend/Faculae) |
| 许可证 | 系统文档符号 | [MIT 许可证](https://github.com/Fastwakend/Faculae/blob/main/LICENSE) |

两项使用与其他设置行一致的字体、配色、间距和分隔线，右侧显示外部链接箭头。通过 SwiftUI 原生 `Link` 打开网页，整行可点按；辅助功能标签说明入口用途。

沿用已有浅色 / 深色主图标、应用标识和本地数据格式。项目 MIT 许可证与第三方 Logo、依赖的完整许可声明继续保留。

## 本地验证

- 92 个 Swift 文件的语法、工程与资源引用检查通过。
- 129 项核心 XCTest 与 10 项分享导入测试通过。
- 使用 iOS SDK 27.2 完成主应用、实时活动扩展和分享扩展的 arm64 Release 编译。
- 发布校验通过，安装包中包含两个指定 URL，主应用与扩展版本均为 2.3.4 (36)。
- 图标资源目录与 2.3.3 的已验证资源完全相同；第三方许可文件在安装包中完整保留。

## 设备验收

在浅色 / 深色模式下打开「设置 → 关于」，检查图标和文字可读；分别点击每行左侧、文字、空白及右侧箭头，确认系统打开对应网页。返回 App 后设置页与已有会话保持正常。仓库访问权限由 GitHub 登录账号决定。

Windows / WSL 的编译和静态检查不替代上述真机点按与浏览器跳转验收。
