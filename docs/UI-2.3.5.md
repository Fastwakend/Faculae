# Faculae 2.3.5 (37)

修复推理等级滑杆刻度与所选模型不一致的问题，并在回复通知中增加本次生成耗时。

## 推理滑杆

推理弹窗为支持连续开关和可打断的弹簧动画，会保留其视图。此前切换模型后，档位文字会更新，但原生 Slider 可能沿用上一模型的刻度配置。现在按供应商 ID、模型 ID 和档位列表刷新 Slider 的身份，重新建立对应的范围与刻度；当前档位不参与身份计算，连续拖动时不会重建控件。旧控件延迟提交的选值不会写入新模型。

继续使用苹果原生 Liquid Glass Slider，档位保持为：

| 模型家族 | 档位 |
| --- | --- |
| OpenAI / Claude | Low、Medium、High、Xhigh、Max |
| DeepSeek | Off、Low、High、Max |
| Gemini | Low、Medium、High |

供应商和模型仍通过稳定 ID 选择；排序不改变已选模型和各模型独立的推理设置。回归测试覆盖同时调整供应商与模型顺序、保存再读取、切换三 / 四 / 五档模型，以及发送请求中的模型名和推理参数。

## 回复通知

完成或中断通知在 tokens 后追加本条回复从开始到结束的耗时，例如 `回复已完成 · 1,864 tokens · 02:15`。时间格式为总分钟数和秒数，保留估算 tokens 的 `≈` 标记。不同会话并行生成时，各自使用自己的回复起点计时；计时在结束回调中截取，不包含排队提交系统通知的等待。

## 验证与设备检查

本地已通过 132 项核心 XCTest、10 项分享导入测试和 92 个 Swift 文件的静态工程检查；完成 iOS SDK 27.2 的主应用、实时活动扩展、分享扩展 arm64 Release 编译及 IPA 资源校验。完整记录见 [本地验证](local-validation.json)。

- 连续拖动、快速开关推理弹窗，确认原有动画与拖动保持平滑。
- 将生成中的回复切到后台，确认完成通知显示 tokens 和本次耗时；并行生成时确认耗时各自对应正确回复。
