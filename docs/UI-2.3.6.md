# Faculae 2.3.6 (38)

## 按需联网搜索

开启联网后，模型会结合上下文决定是否搜索，并自行生成查询词。需要核实的内容可以发起补搜。查询开始后显示搜索进度，回复中的引用可以打开对应的网页来源。

- **DeepSeek 托管搜索**通过官方 `deepseek-flash` 聊天接口调用内置工具，随回复接收搜索结果与引用。后续对话可以继续使用已读取的网页。
- **独立搜索服务**由支持函数调用的对话模型发起搜索。Faculae 执行查询，把结果交回模型。现有 DeepSeek Search / Fetch、Tavily、Brave、Serper、SearXNG 和自定义服务仍可使用。
- **按供应商记忆方案**会在切回供应商时恢复它上次选的搜索服务。同一供应商的模型共用设置，重启后也会保留。

## 构建与安装

发布包包含主应用、实时活动扩展和分享扩展，需要一起签名后安装。Windows / WSL 构建通过 iOS arm64 编译和 IPA 完整性检查。模型接口与真机搜索交互应使用实际配置验收。
